# Pierre's Nix Configurations

This repository contains the configurations of my computers, laptops,
home-servers and perhaps more in the future.

I share it publicly hoping it comes useful for another nix user,
I went through many other configurations like this when I got started myself.
Feel free to steal some ideas, though this configuration is certainly tailored
to my personal usecases.

I still have a lot to learn, so this is far from a perfect example. I certainly wish
I had learned about NixOS Modules from the start.

## Goals

There are three purposes to this configuration:
- Deploying a consistent and bespoke personal digital environment accross
  all my devices, operating systems and ecosystems.
- Maintaining a home server hosting all the digital services I need,
  with no reliance on subscriptions or third parties.
- Switch to free and open-source software at every oportunity.

## Generative AI

Generative AI has been widely used in this project for prototyping. Some parts of the nix
code is mostly generated and it shows. However, the main project structure, core components
and critical services are always rewritten by hand.
